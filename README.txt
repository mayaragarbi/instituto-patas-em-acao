# Instituto Patas em Ação

Projeto acadêmico desenvolvido para praticar HTML5 semântico.

## Recursos utilizados

- HTML5 semântico
- Formulários
- Validação nativa com pattern
- Acessibilidade com alt e hierarquia de títulos
- Estrutura com header, nav, main, section, article, aside e footer
- Validação pelo W3C Validator

## Páginas

- Página inicial
- Projetos
- Cadastro

## Estratégia de versionamento

O projeto utiliza uma estrutura baseada no GitFlow:

- master: mantém a versão estável do projeto.
- develop: concentra as alterações em desenvolvimento.
- feature/: utilizada para desenvolver funcionalidades ou alterações específicas de forma isolada.
